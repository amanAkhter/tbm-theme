# Carbonline Theme Specification

Carbonline is an **ultra-clean**, update-proof theme designed for *Antigravity IDE*.

## Design Pillars
1. **Carbon Surfaces**: Restrained background steps (`#0d0f12`, `#12151a`, `#161a22`).
2. **Signature Accent**: Crisp electric teal (`#00d2b4`).
3. **Calm Contrast**: All foreground elements pass WCAG AA / AAA standards.
